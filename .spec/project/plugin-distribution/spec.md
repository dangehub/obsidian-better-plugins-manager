# plugin-distribution — 插件分发

plugin-distribution 管理插件从外部来源进入 Obsidian 的通道，以及用户的配置在实例之间迁移的能力。它确保插件的获取与备份过程安全、可追踪、可重复。

| [[transfer-pack]] | 配置包的导出、导入、预览与应用 |
